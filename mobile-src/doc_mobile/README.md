# nodejs-mobile docs

These are the docs that ship with the source tree and with each release tag.

- [BUILDING.md](./BUILDING.md) — build `libnode.so` (Android) and
  `NodeMobile.xcframework` (iOS) by hand, host requirements, and the
  `full` / `lite` flavors.
- [TESTING.md](./TESTING.md) — the test tiers, what CI runs, and how to run
  the suites locally on an emulator, a simulator, or a device.
- [FAQ.md](./FAQ.md) — what is and isn't supported when running Node.js on
  mobile platforms.
- [CHANGELOG.md](./CHANGELOG.md) — release history.

This source tree is generated from the project's
[`patches` branch](https://github.com/nodejs-mobile/nodejs-mobile/tree/patches),
which holds the mobile patch series, the tooling, and the docs on
contributing, upgrading upstream, and releasing.
