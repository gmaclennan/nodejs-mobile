# Curated Tier 2 subset (docs/TESTING.md on the recipe branch): single-process
# test/parallel cases validated to pass on BOTH a real arm64 Android emulator
# and an iPhone simulator. One test per line; blank lines and '#' comments are
# ignored.
#
# Harvested by running pure-JS categories (buffer, events, url, querystring,
# string-decoder, path, crypto hash/hmac/cipher, util) through the proxy on both
# devices and keeping the intersection of passes. Re-run that harvest on a fresh
# device to grow coverage — the procedure is in docs/TESTING.md on the recipe
# branch, "Expanding the curated list".
#
# This is an ALLOW-list: a test that is neither listed here nor skipped in
# test/parallel/parallel.status never runs on a device, and nothing in a green
# run says so. That is currently ~95% of the runnable suite; see
# tools/mobile-test/coverage-manifest.py.
#
# Deliberately EXCLUDED from this deterministic list:
#   - test-timers-*  : timing-sensitive; flaky under emulation (pass in isolation,
#                      flake in large batches). Run these in the nightly full
#                      suite with flaky-test retries instead, not here.
#   - test-os        : os.homedir() -> uv_os_homedir ENOENT (no HOME in sandbox).
#   - test-assert    : a message-format check needs the JIT diff; V8 jitless
#                      (required on iOS) emits the short form. Cosmetic.
#   - tests that spawn a child node via process.execPath (buffer-constructor-
#     node-modules, url-parse-deprecation, url-parse-invalid-input): on the iOS
#     simulator execPath is the testnode binary and posix_spawn is permitted, so
#     they pass; on Android execPath is app_process64 (not node), so the child
#     SIGABRTs and the test fails. Asymmetric -> not in the both-platforms gate.
# child_process / cluster / fork / signal / OpenSSL-CLI / FIPS cases are excluded
# by the [$system==android] / [$system==ios] sections in test/*/*.status.
#
# NOTE: the proxy relaunches the app once per test, so it is sensitive to device
# load. Prefer modest batches and a fresh emulator/simulator (as CI provides).

# Fork-only tests. Everything above is an upstream test that happens to pass
# on mobile; these exist to exercise the patch series itself, and each one
# names the patch it covers (docs/TESTING.md, "What covers which patch").
# They are the entries for which the *device* legs are the point: several of
# these patches only change behaviour on Android or iOS, so a host run proves
# the assertion is well-formed and the Tier-2 run is what actually gates it.
# ---------------------------------------------------------------------------
# Patch 0006/0007: the POSIX credential surface. Upstream has none of it on
# Android; the fork turns it back on and removes the setters bionic and the
# app sandbox cannot honour.
parallel/test-mobile-credentials
# The one entry here that is NOT pure JS: a global fetch() against an
# in-process HTTP server. It is the gate for the WebAssembly polyfill the iOS
# binary needs for fetch() to work at all (docs/FAQ.md on the recipe branch).
# Verified on a host build run --jitless (the same engine iOS gets, gated by
# host-smoke); the Tier-2 emulator/simulator run is what confirms it on device.
parallel/test-mobile-fetch
# Patch 0015: NODE_PATH is read from process.env rather than through
# SafeGetenv(), whose "is this process secure" check is meaningless when node
# is a library inside somebody else's app.
parallel/test-mobile-node-path
# Patch 0010: the Apple system trust store reader, whose macOS-only API is
# fenced off on iOS. The reader has no other caller, so without this the whole
# thing can stop returning certificates with every job still green.
parallel/test-mobile-system-ca
# No patch: unix domain sockets. Every upstream UDS test is skipped on iOS
# because the app container makes the socket path exceed Darwin's 104-byte
# sun_path, so nothing gated UDS there at all. This binds a short relative path,
# which is the portable form and the one an embedder should use.
parallel/test-mobile-unix-socket
# Patch 0008: KVStore::Clone() skips a variable it cannot read back instead of
# throwing away the whole environment, which is how a worker gets one at all
# on Android.
parallel/test-mobile-worker-env-clone
